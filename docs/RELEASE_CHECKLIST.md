- [x] Python/TypeScript format, lint, type, test, migration, build, dependency, and container gates are configured.
- [x] Production settings reject development secrets and insecure cookies.
- [x] Non-root containers, one-shot migrations, worker, health checks, persistence, HTTPS proxy example, and deployment guidance exist.
- [x] README, architecture, setup, API, deployment, security, contribution, changelog, release notes, limits, and roadmap are present.
- [x] Sites captured the validated release landing page for the hosted portfolio.
- [ ] Operator supplies production secrets, DNS/TLS, backup/restore proof, the
  real GitHub repository URL, and a recorded demo before broader public launch.
