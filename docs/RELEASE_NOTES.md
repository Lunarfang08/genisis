# GENESIS 1.0.0-rc.1

GENESIS is now an end-to-end local-first civilization simulator release candidate. Owners can configure scenarios, observe real world state and history, inspect cities and analytics, compare dates, export evidence, control a resumable live simulation, and use an optional bounded AI narrative layer. A public browser-only deterministic demo requires no login or provider call.

This is a portfolio release candidate, not a hosted multi-tenant SLA. Validate the provided 1k/10k/50k benchmark on target hardware, configure HTTPS and secrets, and complete a backup/restore drill before public deployment.
