# GENESIS Web

The GENESIS observation deck is a responsive Next.js application built with the
App Router, strict TypeScript, Tailwind CSS, and the vinext runtime.

The release candidate includes public portfolio/demo pages, authentication, a
scenario wizard, private worlds, live controls, historical charts, 2D city
visualization, timelines, and exports. Empty states never invent world data.

```bash
npm run dev --workspace @genesis/web
npm run typecheck --workspace @genesis/web
npm run lint --workspace @genesis/web
npm run test --workspace @genesis/web
```
